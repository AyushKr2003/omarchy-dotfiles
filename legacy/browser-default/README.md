# Omarchy browser homepage

A local start page that follows your live Omarchy theme -- clock,
time-of-day greeting, working search, and quick links to the Omarchy
ecosystem (Manual, GitHub, ISO, Discord).

## How it stays themed

`colors.css` is regenerated on every theme switch by
`~/.config/omarchy/hooks/theme-set.d/30-browser-default-homepage`, the
same hook mechanism used for the Firefox/LibreWolf/Zen `userChrome.css`
theming. `style.css` and `default.html` never hardcode a color -- every
color reference is a `var(--...)` defined in `colors.css`, so this
page reflects whatever Omarchy theme is active without needing any
browser extension, and without needing this repo to touch anything
outside its own folder.

A fallback `colors.css` ships in this repo so the page still looks
right even before the hook has run for the first time; it gets
overwritten the moment you next switch themes.

## Setting it as your homepage

The page lives at a fixed local path:

```
file://~/.config/browser-default/default.html
```

(expand `~` to your actual home directory, e.g.
`file:///home/yourname/.config/browser-default/default.html`)

**Firefox / LibreWolf / Zen** (all share the same settings UI):
`about:preferences#general` → **Home** → **Homepage and new windows** →
**Custom URLs…** → paste the `file://` path above.

**Chrome / Brave / Edge** (Chromium family):
`Settings` → **On startup** → **Open a specific page or set of pages**
→ **Add a new page** → paste the `file://` path above. Optionally also
set it under `Settings` → **Appearance** → **Show home button** →
**Enter custom web address**.

## Personalizing

- Click the greeting once to set a name -- stored only in that
  browser's `localStorage`, never sent anywhere, and easy to clear by
  leaving the prompt blank.
- Click the search engine name (under the search bar) to cycle through
  DuckDuckGo / Google / Kagi / Startpage. Your choice is remembered per
  browser.

## Files

| File | Regenerated by hook? | What it's for |
|---|---|---|
| `default.html` | No | Markup |
| `reset.css` | No | Minimal reset |
| `style.css` | No | All layout/typography -- reads colors, never sets them |
| `script.js` | No | Clock, greeting, search engine switching |
| `colors.css` | **Yes** | The only file the theme-set hook touches |
